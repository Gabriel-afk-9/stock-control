Aqui está o passo a passo para rodar e usar o Estocaí. (Estou em modo de plano, então só apresento o guia — nenhuma ação foi executada.)
Pré-requisitos
- Node.js 20+ e npm instalados.
- O projeto está em estocai/ (raiz do repo).
1. Instalar dependências
cd estocai
npm install

2. Configurar o ambiente (.env)
Crie o arquivo .env na raiz de estocai/ com:
DATABASE_URL="file:./dev.db"
JWT_SECRET="um-segredo-bem-longo-com-pelo-menos-32-caracteres-xxxxxxxx"
LOG_LEVEL="debug"
ADMIN_PASSWORD="admin123"
ALMOXARIFE_PASSWORD="almoxarife123"
REQUISITOR_PASSWORD="requisitor123"
No Windows PowerShell você pode copiar o exemplo: copy .env.example .env e depois editar o JWT_SECRET.

3. Subir o banco (SQLite) e popular dados
npx prisma generate
npx prisma migrate dev      # aplica as migrations e roda o seed automaticamente
Se preferir aplicar sem interação: npx prisma migrate deploy e depois npx prisma db seed.
Isso cria dev.db e insere 3 usuários (ver abaixo).

4. Rodar em desenvolvimento
npm run dev
Acesse http://localhost:3000 → você será redirecionado para /login.

5. Fazer login (usuários do seed)
E-mail	Senha	Papel (permissões)
admin@estocai.com	admin123	ADMIN — acesso total (criar/excluir produtos)
almoxarife@estocai.com	almoxarife123	ALMOXARIFE — criar/excluir produtos
requisitor@estocai.com	requisitor123	REQUISITOR — só visualiza
Observação: o login tem rate-limit de 5 tentativas/minuto por IP.

6. Usando o sistema
- /dashboard/inventory — lista produtos com busca (nome/SKU) e paginação. Use o formulário de busca e a paginação. ADMIN/ALMOXARIFE podem criar (formulário) e excluir produtos; REQUISITOR vê a lista mas ações sensíveis são bloqueadas por requireRole.
- /dashboard/alerts — alertas de estoque (produtos abaixo do minStock).
- /dashboard/users, /dashboard/settings, /dashboard/request, /dashboard/monthly-requests — demais telas do dashboard.
- O status de cada produto (IN_STOCK / LOW_STOCK / OUT_OF_STOCK) é derivado de quantity vs minStock.

7. Produção (opcional)
# .env com NODE_ENV=production e JWT_SECRET forte
npx prisma migrate deploy
npm run build
npm run start
Recomendado trocar SQLite por PostgreSQL (ver README).

8. Testes (opcional)
npm test                 # roda os 67 testes (Vitest)
npm run test:coverage    # com relatório de cobertura
npm run lint             # ESLint
npx tsc --noEmit         # checagem de tipos
